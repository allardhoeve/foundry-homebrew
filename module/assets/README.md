# Assets

Third-party and project assets for the Foundry homebrew module.

## Source: Torchlight Timer

Downloaded from https://www.torchlighttimer.com/

### Video (`video/`)

Torch lifecycle animations:

| File | Description |
|------|-------------|
| `ignite.mp4` | Torch ignition |
| `yellow.mp4` | Bright flame (early burn) |
| `orange.mp4` | Dimming flame (mid burn) |
| `red.mp4` | Fading flame (late burn) |
| `extinguish.mp4` | Torch going out |
| `darkness.mp4` | Full darkness |

Spell (staff) lifecycle animations:

| File | Description |
|------|-------------|
| `staffIgnite.mp4` | Staff light activation |
| `staff.mp4` | Staff glow (sustained) |
| `staffExtinguish.mp4` | Staff light fading out |

### Audio (`audio/`)

Converted from WAV to MP3 (128kbps) to reduce repo size.

| File | Description |
|------|-------------|
| `torchSound.mp3` | Torch burning ambient sound |
| `staffGlowSound.mp3` | Staff glow ambient sound |
| `torchEndSound.mp3` | Torch extinguishing sound |
