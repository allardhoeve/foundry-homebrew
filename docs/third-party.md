# Third-Party Notes

Last updated: 2026-02-04

This repo may include third-party code or references. When we add external sources,
we track their licenses here and keep a strict separation between local examples
and upstream sources.

## Current Policy
- Prefer links for restrictive or unclear content.
- Use submodules for large upstream repos to preserve attribution and history.
- Copy only small, high-value examples locally, with explicit attribution and
  license compatibility checks.
